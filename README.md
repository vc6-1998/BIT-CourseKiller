# BIT 本科生抢课系统

适用于北京理工大学本科生补选退换课、试听退换课等先到先得阶段。程序会监控 `courses.txt` 中指定的精确教学班，在出现名额后提交选课，并查询后台的最终处理结果。

目前支持：

- 系统推荐课程
- 校公选课/拓展英语
- 体育课
- 校园网直连与校外 WebVPN 自动切换
- 登录会话本地恢复
- 统一身份认证按需短信验证
- 断网或登录失效后自动恢复

## 安装

建议使用虚拟环境，然后安装依赖：

```powershell
pip install -r requirement.txt
```

依赖包括 `requests`、`beautifulsoup4` 和 `pycryptodome`。

## 配置课程

编辑项目目录中的 `courses.txt`。每行由三个逗号分隔的字段组成：

```text
课程类别,课程号,教学班号
```

课程类别使用以下代码：

- `TJKC`：系统推荐课程
- `XGXK`：校公选课/拓展英语
- `TYKC`：体育课

例如：

```text
# 以 # 开头的行和空行会被忽略
TJKC,100001,01
XGXK,200002,03
TYKC,300003,12
TYKC,300003,15
```

程序先用课程号精确搜索，再用教学班号精确匹配，并在每次运行时获取当前批次真正用于提交的内部教学班 ID。匹配不到或匹配到多个教学班时，程序会指出 `courses.txt` 中的错误行并停止，不会退化为名称模糊匹配。

同一课程可以配置多个教学班候选。例如上面的两个体育教学班会同时被监控；其中一个选课成功后，同类别、同课程号的其他候选会立即停止提交。

`courses.txt` 是只读配置，程序不会自动修改它。

## 运行

```powershell
python main.py
```

程序依次执行：

1. 检测校园网直连；不可用时尝试 WebVPN。
2. 恢复本地登录会话，失效时再进行人工认证。
3. 读取当前选课批次和校区。
4. 精确解析并显示 `courses.txt` 中的教学班。
5. 询问 `是否开始抢课？(y/n)`。
6. 输入 `y` 后开始循环查询和提交，其他输入直接退出。

按 `Ctrl+C` 可以随时安全停止程序。

## 登录和本地会话

登录成功后，程序会在本地生成 `session.json`，其中保存选课 token 和 Cookie，不保存密码。下次启动时会先验证该会话：

- 选课会话仍有效：直接继续使用。
- 选课 token 失效但统一认证 Cookie 有效：自动获取新 token。
- 全部失效：重新要求输入密码。

校园网直连和 WebVPN 会话分别保存在 `direct` 和 `webvpn` 条目中，切换网络不会互相覆盖。

如果统一身份认证要求短信二次验证，程序会先完成手机号查询，再自动发送验证码并在终端提示输入六位验证码；未触发二次验证时不会显示该步骤。认证流程按学校当前 CAS 接口处理，不主动申请可信设备。

如需强制重新登录，可以在程序退出后删除 `session.json`。

## 校园网与 WebVPN

两条线路使用同一套课程查询、提交和结果确认逻辑，区别仅位于登录及传输层：

- 校园网直接访问选课系统和统一认证。
- 校外网络先通过统一身份认证取得选课系统 ticket，再登录 WebVPN 网关建立会话。
- 随后把选课系统回调转换为 WebVPN 包装地址访问，并携带网关 Cookie 和必要的 VPN 参数。

所有请求都忽略操作系统的 HTTP/HTTPS 代理设置。程序优先尝试校园网直连，直连不可用时自动选择 WebVPN。

## 抢课与异常恢复

程序仅向配置中精确解析出的教学班 ID 提交请求。选课接口受理请求后，还会轮询后台处理状态；只有后台明确返回成功才会将该课程视为完成。

运行期间遇到临时断网、半截响应或网站偶发返回异常时，程序会放弃本轮请求并立即继续查询，不会把普通请求异常误判为密码或短信问题。只有服务器明确返回登录状态失效时，程序才会恢复已保存的会话或重新登录；恢复成功后会重新解析教学班并再次显示“正在查询精确教学班”。

默认查询间隔为一秒，可通过 `main.py` 中的 `COURSE_SCAN_INTERVAL` 调整。

## 文件说明

- `main.py`：网络检测、会话恢复、课程解析和抢课主循环。
- `verify.py`：统一身份认证、WebVPN 网关流程和选课系统注册登录。
- `sso_client.py`：按 BIT-Login-Python 实现移植的 CAS、风控、加密和短信认证客户端。
- `courses.txt`：手动维护的教学班配置。
- `session.json`：运行后生成的本地会话文件。
- `encrypt.py`：登录参数加密。
- `requirement.txt`：Python 依赖。

## 安全提示

- `session.json` 相当于临时登录凭证，请勿上传、分享或同步到公共位置。
- `session.json` 和临时会话文件已经写入 `.gitignore`。
- 请在终端中运行程序，密码输入不会回显。
- 浏览器与脚本同时登录选课系统时，学校服务器可能使其中一方的会话失效。
- 请遵守学校选课规则，并自行确认课程、时间冲突和培养方案要求。
